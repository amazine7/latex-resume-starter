## 这个模板是什么

本仓库基于武汉大学简历模板整理而来。核心版式、结构和主要设计基本沿用原武汉大学模板，没有做本质替换；本仓库主要做的是编译适配、文件整理和修改提示。

你可以把它当作原模板的“可编译 starter”：把仓库文件下载下来，准备好校徽，按下面的提示替换个人信息、教育经历、项目经历等内容，就能直接嵌套使用，不需要重做版式。

> 非武汉大学官方仓库。校徽及原模板相关权利归各自权利人，校徽请从学校官方渠道获取，仅用于个人求职简历，请勿商用。若原模板有作者或来源声明，请保留并注明。

> 依赖说明：LaTeX 负责编译，brain 负责想清楚你写了啥。
